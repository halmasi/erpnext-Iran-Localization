# Changelog

## 0.1.0 — 2026-10-06 (local, unpublished)

- Standard app-owned settings DocType and migration of the existing custom schema.
- Idempotent safe defaults; preserve site values, disabled flags and encrypted passwords.
- Modular optional validation with Persian/Arabic digits and personal/legal checksum checks.
- BOM pricing in dependency order, unit-output quantities, default BOM selection and currency conversion.
- Persian invoice print format with Jalali date and stored party identity snapshots.
- Replaceable SMS/taxpayer provider registry, test providers, Kavenegar and HTTP taxpayer gateway adapter.
- Auditable immutable requests, provider/account fingerprint, explicit dispatch/retry/reconciliation.
- Authenticated commerce catalog, ERPNext price/tax calculation and idempotent draft orders.
- Localization Workspace, setup actions, test suite and installation/provider documentation.
